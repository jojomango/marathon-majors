Privacidad

Qué datos recoge este sitio

Este es un sitio web estático, sin cuentas, comentarios ni formularios. Nunca pide tu nombre, tu correo electrónico ni otros datos personales.

Google Analytics

Este sitio usa Google Analytics 4. En tu primera visita se te pide el consentimiento, y Google Analytics solo se carga, con sus cookies de análisis, después de que elijas «Aceptar». Sirve para contar:

  • qué páginas de carreras ves, durante cuánto tiempo y en qué idioma de la interfaz
  • tu región aproximada y el tipo de dispositivo y navegador
  • desde qué sitio web llegaste

Los datos solo se usan para saber qué contenidos interesan más y mejorar el sitio. Las direcciones IP se anonimizan. Google trata y conserva los datos según su política de privacidad.

Si eliges «Rechazar», no se carga ningún código de seguimiento.

Idioma

El idioma que eliges en el selector se guarda en tu propio navegador (localStorage) y solo sirve para mostrar el mismo idioma la próxima vez.

Cambiar tu elección

Tu elección sobre las cookies de análisis también se guarda solo en tu navegador. Con el botón de abajo puedes borrarla y se te volverá a preguntar en la página de inicio. También puedes borrar los datos del sitio en tu navegador.

Borrada. Se te volverá a preguntar en la página de inicio.

Recursos de terceros

Las fuentes tipográficas las proporciona Google Fonts, así que tu navegador se conecta a los servidores de Google para cargarlas. El sitio está alojado en GitHub Pages, y GitHub puede guardar registros de acceso según sus propias políticas.

Contacto

Si tienes preguntas sobre este aviso, abre una issue en el repositorio de GitHub del sitio.

Este es un sitio no oficial hecho por aficionados, sin relación con los organizadores de las carreras ni con Abbott World Marathon Majors. Consulta la web oficial de cada carrera para el recorrido, las fechas y el reglamento.

Recorridos: reconstruidos a partir del mapa oficial de cada carrera con datos viales de OpenStreetMap (distancias ajustadas a 42,195 km). El recorrido de Ciudad del Cabo para 2027 aún no se ha publicado y sigue siendo aproximado. Datos del mapa © OpenStreetMap contributors, con licencia ODbL.

Altitud: USGS 3DEP para las tres carreras de EE. UU.; Copernicus EU-DEM para Londres y Berlín; Autoridad de Información Geoespacial de Japón para Tokio; NASA SRTM para Sídney; obtenidos mediante OpenTopoData y suavizados. No se recoge la altura de los puentes. Todos los perfiles usan la misma escala vertical (160 m), así que se pueden comparar directamente.
